# 买手 Pool Eyeball 工作台

工作台：[打开买手工作台](https://joewu1024.github.io/---2/)

分享给其他买手的空白入口：[新建独立工作区](https://joewu1024.github.io/---2/?new=1)

## 数据与工作区

空白入口每次打开会生成一个随机的独立工作区，并把地址改成 `?workspace=…`。请收藏改写后的地址，下次从收藏继续使用。重新打开 `?new=1` 会创建另一份空白工作区，已有工作区不会被清除。

商品数据、买手编辑、历史版本和自定义选项保存在当前浏览器的本机数据库中。不同设备、不同浏览器配置或不同工作区互相独立，没有账号和云端同步。共享个人工作区地址不会把本机数据传给其他设备；共享产品请使用卡片的在线分享链接。

同一工作区只允许一个标签页编辑，重复标签页会阻止载入和写入。升级后请关闭仍运行旧版的工作台标签，再刷新使用。工作区地址用于本机数据分区，不是身份认证或权限系统。

当前工作自动保存，历史版本提供额外的本机快照。清理浏览器站点数据、使用无痕窗口或更换浏览器会影响本机存储；请定期导出 Excel 作为外部备份。

历史版本可以修改名称；改名只更新显示名称，版本编号和保存的商品快照保持不变。版本管理也支持勾选删除。

是否可开发、不可开发原因在行内和批量填充中使用同一套可输入的选项框。每次点击都展示全部候选，输入时才搜索；自定义候选右上角的 × 从本工作区选项库删除该值，已填写的商品内容保留。默认选项不能删除。批量填充弹窗的标题和底部操作区固定，中间内容可以独立滚动。

表头筛选支持文字包含、不包含、等于、不等于、为空和非空；价格及件数还支持大于等于、小于等于、大于和小于。例如在目标价的筛选条件中选择“大于或等于 ≥”，输入 `50` 后应用。数值条件使用原始价格，空值不按零处理；同列勾选值按“或”、勾选值与条件按“且”、不同列按“且”，筛选与导出覆盖全部记录。每个 model 状态字段也可以独立设置文字条件。条件区、滚动候选区和固定操作区分开显示。

顶部搜索框支持批量 Model ID：将多个数字 ID 用空格分隔，一次最多 100 个不同 ID，按完整 ID 精确匹配任意一个；重复 ID 自动合并，长 ID 和前导零按文本保留。也可从 Excel 纵列粘贴数字 ID，换行和制表符会转为空格。超过 100 个时明确提示减少数量，不截断为部分结果。搜索框的淡色提示标明上限，批量检索期间显示数量；标题、类目等普通文字搜索保持原有行为，批量 ID 与已有表头条件按“且”组合。

单一型号只显示 Model ID 和预览入口，不显示组名、改名或整组操作。真正的多型号组在 Model ID 下方只保留一条组控件：左侧方框选择整组，中间“组名 · N 款”可点击改名，右侧小图标展开或收起型号。未自定义名称时简写为“产品组”，不重复显示 Model ID。整组选中包含折叠、分批和筛选隐藏的全部型号，部分选中显示半选；只有确有筛选隐藏成员时才补充隐藏数量。即使筛选只显示组内一款，也保留完整组名和总数。勾选多个组后点击“合并所选组 / 型号”即可合并，跨页选择会保留；原型号方框仍只选择当前一款，目标价最高的型号仍为组母，结果自动保存。

“合并所选组 / 型号”先打开确认弹窗，显示所选型号图片、Model ID、来源组、筛选外数量及拟定组名；可上下滚动查看全部已选产品，确认才执行合并，取消不改数据。大量选择采用固定行高的滚动窗口，只创建当前附近的产品 DOM。可在弹窗中命名，或点击组母下方的组名修改（最多 80 个字，留空恢复默认名）；组名称会随当前工作区和历史版本保存。Model ID 表头的“组名筛选”和“所有字段筛选”中的“组名称”均支持按名称筛选，顶部全文搜索也能检索组名。名称与内部组编号分开，两个组重名不会自动合并；移出、取消分组及重新载入源表会清除相应旧组名。

## 大数据处理

- CSV 在 Worker 中分段解析，支持 UTF-8、UTF-16 和 GB18030；Excel 在 Worker 中解析，保留文本 ID 和源行号。
- 主数据导入按规范化后的真实 `Model ID` 自动去重，保留 `Non Brand 倒算价` 原始数值最高的完整源记录；同价保留先出现的一行，有效数字优先于空值或无效价格。缺少 Model ID 的行独立保留。去重先于翻译和图片处理，按批次让出界面并支持取消；导入后提示源行数、剔除重复数及保留数。翻译与邀请 ID 附表沿用各自匹配规则。
- 重新导入时，旧重复行中不冲突的人工字段会保留到唯一记录；同字段人工值冲突时取先出现的值（包括人工清空），前置核价信息取第一份人工编辑的完整 Y/N、日期、备注。未标记为人工编辑的旧源字段不会覆盖新选中的最高倒算价记录。
- 补录遗漏商品请使用顶部的“新增数据”。支持 Excel / CSV，仅追加当前工作区不存在的真实 Model ID；已有 ID 整条跳过，即使新文件价格更高，也不覆盖之前的商品、买手编辑和分组。保留当前筛选、搜索、勾选、分页及组展开状态；新增商品先独立展示，只整理和自动翻译新增记录。文件内部重复仍保留 Non Brand 倒算价最高的完整行；缺少 Model ID 的行跳过并提示数量。新增 0 条、取消或文件错误均保持原数据；完成后显示新增、已有跳过和文件内去重数量。“导入 Excel / CSV”继续用于更新整份源表。
- 先展示数据，字段提取、翻译和图片分组分阶段处理。默认不自动图片分组。
- 默认每页 50 组，可选 25/50/100/200；展开大组时每批显示 50 个子型号。筛选及导出作用于全部匹配记录。
- 本机保存按 200 条请求批次写入同一个原子事务；历史快照防止重复点击覆盖版本。
- 大于 500 条的导出分段准备、Worker 生成。导出包含全部表头、买手备注、邀请 ID 和前置核价信息。
- Excel 与 CSV 均导出 34 列：`Model ID` 后紧接 `item_id`，原聚合的 model 状态拆成 7 个独立状态列，保留文本 ID、空值与买手备注。
- 内嵌图片的 Excel 保留兼容解析路径。这类文件的内存与速度取决于图片总大小，不能只按行数衡量。

表格商品缩略图高 88px，宽度随所在列自适应，保持图片比例。鼠标悬停可查看较大预览，移开后关闭；预览浮窗与表格缩略图使用不同尺寸。

## 中文翻译与分享

- 导入后自动在后台补齐标题、型号名和上新类目的实际中文译文，并回填到对应字段；买手手动填写或导入的目标字段优先于自动翻译，`5pcs`、纯数字、外文和混合文字也会原样保护。人工在框内清空的内容保持为空；旧数据中已填但没有可信自动来源的内容会作为买手内容保留。相同待译文本去重并复用缓存，当前页优先处理，大批数据分阶段继续。
- 翻译区只保留 `一键翻译` 和 `导入翻译`。一键翻译会继续补齐未完成内容；导入翻译通过 Model ID 匹配中文标题和型号名。买手无需选择服务或准备模型。
- 主通道采用腾讯 Transmart 整句翻译，按完整标题或型号原句处理，保留返回措辞；原 Google 和浏览器原生翻译代码保留为内部兼容回退。较早的 Google 文档任务工具保留代码兼容，不再作为买手界面操作入口。
- 网络不可达、超时或限流时保留已有译文。尚未取得的中文不会凭空补写，也不会用外文原文冒充；可稍后点击 `一键翻译`，或通过 `导入翻译` 补齐。自动翻译仅发送必要的标题、型号及类目文字，工作台记录不会上传到 GitHub 仓库。
- 单个和多个产品分享均直接记录点击生成时的字段内容，不校验是否含中文，也不启动或等待翻译；未翻译、手工值、旧译文以及空框均可生成链接。预览及在线卡片对空值显示“未填写”，不会把原文写入目标字段。类目优先使用已有译文，无可用译文时展示原类目。单卡在生成期间展示这份快照，生成后仍可复制或在新标签页打开；之后再次编辑或重新打开卡片，可按新内容重新生成。
- 单个和批量分享先在网页内压缩所选产品，生成原站点 `s.html` 的原始链接，再调用买手指定的 WorkBuddy 企微/微信链接卡片工具。分享浮窗自动填入“原始链接”，最终显示、复制和打开工具返回的卡片链接。只有点击生成时才发送这份所选产品链接，未勾选商品及其他工作台数据不会上传；外链工具负责保存原址及卡片信息。外链失败会明确报错，不会把原长链当作成功结果复制。
- 每次最多分享 11 个 Model，工具栏保留醒目提示，仅点击生成且超出数量时弹出提醒，不影响批量编辑。11 是当前由用户实际验证的数量上限。原始链接仍检查 1,800 字符的保守预算，内容过长时提示减少勾选；全部所选产品在同一页按顺序展示。工具调用采用其支持的简单跨域请求，无需买手登录或已有 Cookie。
- 旧 is.gd 链接无法由工作台改写其已保存的跳转目标；如果收件人一直停留在 is.gd，请在新版工作台重新生成并转发直达网址。旧版完整分享数据格式继续兼容。
- 在线查看页内置解码，支持新压缩链接、早期完整链接和已发布的加密归档链接。打开时校验数据格式、长度及校验和。转发收到的链接不完整时，可在分享页粘贴完整原址查看。
- 已公开分享的 `BtrY9i` 的 8 款产品仍可通过[静态直达归档](https://joewu1024.github.io/---2/p/BtrY9i/)查看。该页包含 8 张型号图片和单文件离线备份。

## 验证

`scripts/` 包含功能、翻译通道、类目、分享、工作区、CSV、Excel、分组和导出回归检查。Node 检查使用虚构数据和受控传输；通过单测不代表真实在线翻译可用。`artifacts/` 区分 Node 模块基准与浏览器实际验收结果，报告各自说明验证范围。部署只需保留仓库文件，含 `vendor/` 和 `.nojekyll`。

可用 `node --test --test-isolation=none scripts/check-share-preview.cjs` 检查真实分享预览函数；大数据检查分别运行 `check-large-import.cjs`、`check-large-xlsx.cjs`、`check-large-grouping.cjs` 和 `check-workbench-export.cjs`。Node 计时不代表浏览器渲染帧率或完整买手操作耗时。

内嵌模块更新后运行 `node scripts/sync-translation-engine.cjs`，同步模块并编译检查所有脚本。

Excel 读取使用本地 vendored SheetJS CE 0.20.3；来源、校验和与 Apache-2.0 许可证见 `vendor/`。
