## 数据与工作区

空白入口每次打开会生成一个随机的独立工作区，并把地址改成 `?workspace=…`。请收藏改写后的地址，下次从收藏继续使用。重新打开 `?new=1` 会创建另一份空白工作区，已有工作区不会被清除。

商品数据、买手编辑、历史版本和自定义选项保存在当前浏览器的本机数据库中。不同设备、不同浏览器配置或不同工作区互相独立，没有账号和云端同步。共享个人工作区地址不会把本机数据传给其他设备；共享产品请使用卡片的在线分享链接。

同一工作区只允许一个标签页编辑，重复标签页会阻止载入和写入。升级后请关闭仍运行旧版的工作台标签，再刷新使用。工作区地址用于本机数据分区，不是身份认证或权限系统。

当前工作自动保存，历史版本提供额外的本机快照。清理浏览器站点数据、使用无痕窗口或更换浏览器会影响本机存储；请定期导出 Excel 作为外部备份。

## 大数据处理

- CSV 在 Worker 中分段解析，支持 UTF-8、UTF-16 和 GB18030；Excel 在 Worker 中解析，保留文本 ID 和源行号。
- 先展示数据，字段提取、翻译和图片分组分阶段处理。默认不自动图片分组。
- 默认每页 50 组，可选 25/50/100/200；展开大组时每批显示 50 个子型号。筛选及导出作用于全部匹配记录。
- 本机保存按 200 条请求批次写入同一个原子事务；历史快照防止重复点击覆盖版本。
- 大于 500 条的导出分段准备、Worker 生成。导出包含全部表头、买手备注、邀请 ID 和前置核价信息。
- 内嵌图片的 Excel 保留兼容解析路径。这类文件的内存与速度取决于图片总大小，不能只按行数衡量。

Google 整句翻译只发送标题、型号名和分享需要的类目文字。人工译文优先；问号或参数差异仅提示核对，不会据此把 Google 已返回的中文清空。网络不可达或限流时保留已有译文。工作台记录不会上传到 GitHub 仓库。

## 中文翻译与分享

- 在线模式发送完整标题或型号原句，保留 Google 返回措辞，不再按品牌拆句、拼词或强制改写术语。旧自动译文在有效新译文成功前继续显示；`重译全部自动中文` 保留人工编辑和导入的中文。
- `启用 Chrome 本地翻译` 为可选方案，需桌面浏览器支持 Translator API 并下载对应模型。界面显示已准备语言，必要时明确显示经英语转换；它与 Google 网页结果可能不同。首次模型准备需点击触发。
- `Google 官方整表翻译` 按语言、每批最多4000条去重原文生成 Excel。下载后在 Google Translate 的文档页面翻译，再导入对应任务的译文。文件仅包含随机任务键和待译原文；真实Model ID、价格和备注不随文件发送。映射保存在本工作区，回填按任务键匹配而非行顺序；冲突、未知键、原文变动及人工字段受到保护。这是网页上传/下载流程，不是隐藏调用Google网页接口。
- Google 官方文档翻译支持不超过10MB的 `.xlsx`：[Google说明](https://support.google.com/translate/answer/2534559?co=GENIE.Platform%3DDesktop&hl=en-FM)。匿名在线端点不保证稳定；若需持续自动的Google云翻译，需要正式Cloud Translation配置。
- 分享预览会异步补齐中文、保留重试和补全入口。新分享链接要求中文标题及型号非空；旧链接缺字段时明确提示补全。分享页面不会用外文原文冒充中文。

## 验证

`scripts/` 包含功能、翻译、工作区、CSV、Excel、分组和导出回归检查。`artifacts/` 区分 Node 模块基准与浏览器实际验收结果，数据均为虚构。部署只需保留仓库文件，含 `vendor/` 和 `.nojekyll`。

内嵌模块更新后运行 `node scripts/sync-translation-engine.cjs`，同步模块并编译检查所有脚本。

Excel 读取使用本地 vendored SheetJS CE 0.20.3；来源、校验和与 Apache-2.0 许可证见 `vendor/`。
