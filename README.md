# 买手 Pool Eyeball 工作台

工作台：[打开买手工作台](https://joewu1024.github.io/---2/)

分享给其他买手的空白入口：[新建独立工作区](https://joewu1024.github.io/---2/?new=1)

## 数据与工作区

空白入口每次打开会生成一个随机的独立工作区，并把地址改成 `?workspace=…`。请收藏改写后的地址，下次从收藏继续使用。重新打开 `?new=1` 会创建另一份空白工作区，已有工作区不会被清除。

商品数据、买手编辑、历史版本和自定义选项保存在当前浏览器的本机数据库中。不同设备、不同浏览器配置或不同工作区互相独立，没有账号和云端同步。共享个人工作区地址不会把本机数据传给其他设备；共享产品请使用卡片的在线分享链接。

同一工作区只允许一个标签页编辑，重复标签页会阻止载入和写入。升级后请关闭仍运行旧版的工作台标签，再刷新使用。工作区地址用于本机数据分区，不是身份认证或权限系统。

当前工作自动保存，历史版本提供额外的本机快照。清理浏览器站点数据、使用无痕窗口或更换浏览器会影响本机存储；请定期导出 Excel 作为外部备份。

历史版本可以修改名称；改名只更新显示名称，版本编号和保存的商品快照保持不变。版本管理也支持勾选删除。

每个多型号商品组的 Model ID 下方提供“整组选中”方框，包含折叠、分批和筛选隐藏的全部组内型号；筛选隐藏数量会单独标明。勾选多个组后点击“合并所选组 / 型号”即可一次合并，跨页选择会保留。原型号方框仍只选择当前一款，组内只勾部分时整组选框显示半选；批量栏显示全部已选数量与当前未显示数量。合并后自动展示新组，目标价最高的型号仍为组母，结果自动保存。

## 大数据处理

- CSV 在 Worker 中分段解析，支持 UTF-8、UTF-16 和 GB18030；Excel 在 Worker 中解析，保留文本 ID 和源行号。
- 先展示数据，字段提取、翻译和图片分组分阶段处理。默认不自动图片分组。
- 默认每页 50 组，可选 25/50/100/200；展开大组时每批显示 50 个子型号。筛选及导出作用于全部匹配记录。
- 本机保存按 200 条请求批次写入同一个原子事务；历史快照防止重复点击覆盖版本。
- 大于 500 条的导出分段准备、Worker 生成。导出包含全部表头、买手备注、邀请 ID 和前置核价信息。
- Excel 与 CSV 均导出 34 列：`Model ID` 后紧接 `item_id`，原聚合的 model 状态拆成 7 个独立状态列，保留文本 ID、空值与买手备注。
- 内嵌图片的 Excel 保留兼容解析路径。这类文件的内存与速度取决于图片总大小，不能只按行数衡量。

表格商品缩略图高 88px，宽度随所在列自适应，保持图片比例。鼠标悬停可查看较大预览，移开后关闭；预览浮窗与表格缩略图使用不同尺寸。

## 中文翻译与分享

- 导入后自动在后台补齐标题、型号名和上新类目的实际中文译文，并回填到对应字段；已有有效中文、人工修改和导入的中文优先保留。相同待译文本去重并复用缓存，当前页优先处理，大批数据分阶段继续。
- 翻译区只保留 `一键翻译` 和 `导入翻译`。一键翻译会继续补齐未完成内容；导入翻译通过 Model ID 匹配中文标题和型号名。买手无需选择服务或准备模型。
- 主通道采用腾讯 Transmart 整句翻译，按完整标题或型号原句处理，保留返回措辞；原 Google 和浏览器原生翻译代码保留为内部兼容回退。较早的 Google 文档任务工具保留代码兼容，不再作为买手界面操作入口。
- 网络不可达、超时或限流时保留已有译文。尚未取得的中文不会凭空补写，也不会用外文原文冒充；可稍后点击 `一键翻译`，或通过 `导入翻译` 补齐。自动翻译仅发送必要的标题、型号及类目文字，工作台记录不会上传到 GitHub 仓库。
- 分享卡片直接展示完整的已译中文标题、型号及中文上新类目，中文与类目回填后自动刷新。卡片保留生成在线链接、复制和在新标签页打开功能，不提供翻译、重试或补全按钮。中文未完成时不生成新的空字段链接，简洁提示使用工作台上方的一键翻译；旧链接缺中文时明确提示联系分享者补全。

## 验证

`scripts/` 包含功能、翻译通道、类目、分享、工作区、CSV、Excel、分组和导出回归检查。Node 检查使用虚构数据和受控传输；通过单测不代表真实在线翻译可用。`artifacts/` 区分 Node 模块基准与浏览器实际验收结果，报告各自说明验证范围。部署只需保留仓库文件，含 `vendor/` 和 `.nojekyll`。

可用 `node --test --test-isolation=none scripts/check-share-preview.cjs` 检查真实分享预览函数；大数据检查分别运行 `check-large-import.cjs`、`check-large-xlsx.cjs`、`check-large-grouping.cjs` 和 `check-workbench-export.cjs`。Node 计时不代表浏览器渲染帧率或完整买手操作耗时。

内嵌模块更新后运行 `node scripts/sync-translation-engine.cjs`，同步模块并编译检查所有脚本。

Excel 读取使用本地 vendored SheetJS CE 0.20.3；来源、校验和与 Apache-2.0 许可证见 `vendor/`。
